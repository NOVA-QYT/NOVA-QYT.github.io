# Personal Website

Plain HTML/CSS/JS, no build step. Hosted on GitHub Pages at https://nova-qyt.github.io

## Edit content
- `index.html` — bio, news, selected publications
- `publications.html` — full publication list (Abs / Bib toggles)
- `projects.html` — pulls public non-fork repos from GitHub automatically
- `interests.html` — hobby cards, reading list, photo gallery
- Photos go in `assets/img/` (profile) and `assets/img/interests/`
- Search for `TODO` and `[` placeholders.

## Preview locally
    python3 -m http.server 8000
